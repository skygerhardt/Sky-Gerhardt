## Instructions for AI Agents

When working in this repository:

1. Keep all writing professional, clear, concise, and appropriate for recruiters, professors, and potential employers.

2. Preserve Skylar's personal voice. Writing should sound confident and natural rather than overly technical or robotic.

3. Do not invent accomplishments, work experience, education, certifications, skills, or numerical results.

4. Use measurable accomplishments when verified information is available.

5. Emphasize transferable skills including:
   - Leadership
   - Teamwork
   - Discipline
   - Communication
   - Financial analysis
   - Business strategy
   - Entrepreneurship
   - Data analysis
   - Presentation skills

6. When adding projects, explain:
   - The business problem
   - The analysis or approach
   - Tools used
   - Key findings
   - Skills demonstrated

7. Keep Markdown formatting consistent throughout the repository.

8. Use clear headings and bullet points so information is easy to scan.

9. Keep the portfolio appropriate for a business and finance audience.

10. Update the prompt log whenever AI is used to make a meaningful change to the portfolio.

## File Organization

Use the following general structure:

- `README.md` — professional introduction and portfolio homepage
- `RESUME.md` — resume
- `projects/` — portfolio projects and analyses
- `assets/` — supporting images, charts, and other files
- `prompts/` — AI prompt history or supporting AI workflow documentation
- `PROMPT_LOG.md` — record of meaningful AI prompts used to build the portfolio
- `AGENTS.md` — instructions for AI agents working in the repository
- `CLAUDE.md` — additional AI assistant instructions
- `.gitignore` — files Git should ignore

## Prompt Log Rule

After every meaningful AI-assisted work session in this repository, append a new entry to `prompt-log.md`.

Each entry should include:

- Date
- What I asked the AI to help with
- What the AI produced
- What needed correction or improvement
- How I reviewed or verified the result
- Final outcome or decision

Append entries as sessions happen. Never backfill old sessions or invent work that was not documented at the time.
